== Why was there only one "Nr pr" Number in the Case File?

=== 1. Why only _one_ "`Nr pr.`" in the surviving file?

* The *protocol number* was assigned once when the case was formally
opened in the Rentkammer.
* Every subsequent document in the case (reports, cover slips,
rescripts, replies) still _belonged_ to that protocol entry — but the
number itself didn’t need to be re-written on every single sheet.
* So, "`Nr pr. 1274`" = the _umbrella identifier_ under which the whole
Krückeberg loan matter was logged in the protocol book.

That’s why you see it on Document 1 (the petition) but not again: it was
the *anchor document* of the protocol entry.

=== 2. Then why so many "`KRes.`" and "`Rescr.`" notes?

* Every time the Rentkammer issued an *order or instruction* (a
_Reskript_), clerks annotated the document in the file with "`KRes.`" or
"`Rescr.`" and the directive.
* These are *internal instructions* tied back to the same protocol
entry.
* In the protocol book itself, each of those rescripts would have been
noted under the *same protocol number (1274)* as follow-up actions.

So:

* Nr pr. = the umbrella case entry.
* KRes./Rescr. = individual executive actions, which were linked back to
that one protocol number.

=== 3. Why don’t we see the protocol number on each Reskript?

Because the clerks didn’t need to repeat it — they were working inside
the same bound dossier. The NC number (document traffic control) was
enough to keep order within the case file. For institutional memory, you
went to the protocol book and looked up Nr pr. 1274, where you would
find:

* "`Petition of Colon Krückeberg, 2 Oct 1841`"
* "`Amt report, 7 Oct 1841`"
* "`Rescript of 14 Oct 1841`"
* …and so on, all summarized in sequence.

✅ So, the short answer is:

* The Krückeberg matter had *one protocol entry* (Nr pr. 1274).
* All seven Rentkammer orders (_KRes./Rescr._) were written under that
umbrella in the protocol book, but the number wasn’t recopied onto every
slip in the physical case file.
