= Administrative File Label

== Summary

This "document" is an *Administrative file label*, a brief title added
by clerks to identify the case file in storage. It has no legal or
procedural significance.

It was likely written after the Rentkammer had reviewed Jobst
Heinrich's petition, and the report they subsequently requested from
the administrative offices of Bückeburg and Arensburg on the financial
circumstances and the personal qualities of the petitioner.  Since the
report was favorable, the Rentkammer, then, approved petition and this
descriptive file label and placed into the case file.
