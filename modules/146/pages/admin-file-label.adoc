= Administrative File Label

== Summary

This "document" is an *Administrative file label* likely written after the
Rentkammer had reviewed Jobst Heinrich's petition, and the report they
subsequently requested from the administrative offices of Bückeburg and
Arensburg on the financial circumstances and the personal qualities of the
petitioner. Since the report was favorable, the Rentkammer, then, approved
petition and this descriptive file label and placed into the case file.

[NOTE]
====
Administrative file covers identify individuals by occupation and
administrative association (e.g., place of work or handling), not necessarily
by residence. The label *“des Schneiders Krückeberg in Evesen”* (the tailor
in Evesen) therefore does not assert domicile. Consistent church records
identifying Krückeberg as resident at Berenbusch No. 10 carry greater evidentiary
weight for residence.
====

des Schneiders Krückeberg

.Translation
[literal.bordered,subs="verbatim,quotes"]
....
To
the Princely Rent Chamber

of the tailor Krückeberg
in Evesen

Most humble petition
and request

for the gracious granting
of a plot of land for the construction of a house
....
